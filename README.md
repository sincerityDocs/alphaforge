# AlphaForge - AI Agent Crew for Crypto & Memecoin Trading

## Overview
Autonomous multi-agent system for discovering, analyzing, and trading memecoins and crypto using CrewAI.

## Quick Start
1. `pip install crewai crewai-tools`
2. Copy `.env.example` to `.env` and add your API keys
3. `python main.py`

## Structure
- `main.py` - Main crew execution
- `agents/` - Individual agent definitions
- `tasks/` - Task definitions
- `tools/` - Custom tools (on-chain, sentiment, etc.)

**High Risk Warning**: Trading crypto and memecoins involves substantial risk of loss. Start with paper trading only.
